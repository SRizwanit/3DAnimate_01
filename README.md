# লাহুরিয়া গ্রামের গল্প — 3D অ্যানিমেটেড ভিডিও

১৯৭৬ সাল, নড়াইলের লোহাগাড়া উপজেলার লাহুরিয়া গ্রাম। প্রহ্লাদ বিশ্বাস, তাঁর পরিবার, আর ফসলি জমির মাঝখানের একলা ভিটা — `story01.mp3`-র ভয়েসওভারের সাথে সিঙ্ক করা, কার্টুন/cel-shaded লুকের 3D ভিডিও, শব্দ-ধরে-শব্দ রঙিন ক্যাপশনসহ।

- **আউটপুট:** ৯:১৬ — **HD 1080×1920** (`out-hd.mp4`) ও **4K 2160×3840** (`out-4k.mp4`), ৩০ fps, ২১৩৯ ফ্রেম (≈ ৭১.৩ সেকেন্ড)
- **টেক:** React + Remotion (মূল রেন্ডার) + `@remotion/three` (three.js) + GitHub Actions
- **আপনার ডিভাইস লাগবে না** — রেন্ডার GitHub-এর সার্ভারে হয়

---

## ১) GitHub-এ আপলোড (একবারের কাজ)

1. [github.com](https://github.com) এ লগইন করে **New repository** বানান (নাম যেমন খুশি; **Public** রাখলে Actions বিনা খরচে চলে)।
2. এই zip খুলে **সব ফাইল একই ফোল্ডারে** (কোনো সাবফোল্ডার নয়) repo-তে আপলোড করুন: repo-র পাতায় **Add file → Upload files**-এ টেনে ছাড়ুন।
   - `story01.mp3` (≈ ১.১ MB) ও বাকি সব ফাইল সরাসরি রুটে যাবে।
3. **`.github/workflows/render.yml` আলাদা করে বসাতে হবে** (লুকানো ফোল্ডার বলে অনেক সময় টেনে আপলোডে বাদ পড়ে):
   - **Add file → Create new file** চাপুন
   - ফাইলের নামের ঘরে হুবহু লিখুন: `.github/workflows/render.yml` (`/` লিখলেই ফোল্ডার তৈরি হয়)
   - zip-এর ভেতরের `render.yml`-এর লেখা কপি করে বসান → **Commit changes**
4. (বিকল্প) কমান্ড-লাইন জানলে: `git init`, `git add .`, `git commit`, `git push` — এতে `.github` ফোল্ডারও নিজে থেকে যায়।

> ফাইলের তালিকা (সব ফ্ল্যাট, শুধু `render.yml` ছাড়া):
> `story1.json`, `story01.mp3`, `package.json`, `tsconfig.json`, `remotion.config.ts`, `declarations.d.ts`, `index.ts`, `Root.tsx`, `Video.tsx`, `theme.ts`, `scenes.ts`, `World.tsx`, `Characters.tsx`, `Scenes.tsx`, `Captions.tsx`, `hyperframes.html`, `README.md`, `3danimate.md`, `.github/workflows/render.yml`

## ২) রেন্ডার চালানো

repo-তে **push** করলেই রেন্ডার নিজে থেকে শুরু হয় (শুধু `.md` ফাইল বদলালে হয় না)। হাতেও চালানো যায়:

1. repo-র **Actions** ট্যাব → বাঁ পাশে **Render Story Video** → **Run workflow**
2. ঐচ্ছিক বিকল্প:
   - **formats** — `both` (HD + 4K একসাথে, দুটি আলাদা জবে), `hd`, বা `4k`
   - **frame_range** — শুধু কিছু ফ্রেম (যেমন `0-90` = প্রথম ৩ সেকেন্ড)। **প্রথমবার পুরো ভিডিও না চালিয়ে `0-90` দিয়ে হালকা চেষ্টা করুন** — ক্যাপশন, ফন্ট ও 3D ঠিক আছে কিনা দ্রুত দেখা যায়। ফাঁকা রাখলে পুরো ভিডিও (০–২১৩৮)
   - **hyperframes** — ঐচ্ছিক ও অযাচাইকৃত ক্যাপশন-ওভারলে (নিচে দেখুন)। ডিফল্টে বন্ধ
3. **Run workflow** চাপুন → চলমান রানে ক্লিক করে লগ দেখুন।

## ৩) ডাউনলোড কোথায় পাবেন

1. **Actions** ট্যাব → শেষ হওয়া রানে (সবুজ ✅) ক্লিক
2. পাতার একদম নিচে **Artifacts** অংশ:
   - **`story-hd`** → `out-hd.mp4` (1080×1920)
   - **`story-4k`** → `out-4k.mp4` (2160×3840)
3. নাম ক্লিক করলে একটি `.zip` নামে; খুলে MP4 পাবেন। আর্টিফ্যাক্ট **১৪ দিন** থাকে, তারপর মুছে যায় — আগে ডাউনলোড করে রাখুন।

## ৪) সময় ও খরচ

- HD জবের সময়সীমা ১২০ মিনিট, 4K জবের ৩৫০ মিনিট (GitHub-এর সর্বোচ্চ সীমা ৩৬০)। 4K-তে কনকারেন্সি ১, HD-তে ২।
- **আসল সময় আমি মাপতে পারিনি।** 3D দৃশ্য CPU-তে রেন্ডার হয় বলে ধীর; 4K, HD-র চেয়ে অনেক বেশি সময় নেবে। প্রথম রানে লগে দেখে নিন প্রতি ফ্রেমে কত সময় লাগছে।
- **Public repo:** Actions বিনা খরচে। **Private repo:** মাসে নির্দিষ্ট ফ্রি মিনিট আছে (আপনার প্ল্যান যাচাই করে নিন); 4K জব সেটা দ্রুত শেষ করে দিতে পারে।
- 4K জব ৩৫০ মিনিটে না শেষ হলে বাতিল হয়ে যাবে। তখন শুধু HD (`formats = hd`) রেন্ডার করুন, বা আমাকে বলুন — 3D আরও হালকা করে দেব।
- একই branch-এ নতুন push এলে আগের চলমান রেন্ডার বাতিল হয় (সময় বাঁচাতে)।

## ৫) নিজের কম্পিউটারে চালাতে চাইলে (ঐচ্ছিক)

Node.js 20 লাগবে।

```
npm install
npm run studio        # ব্রাউজারে প্রিভিউ (Remotion Studio)
npm run render:hd     # out-hd.mp4
npm run render:4k     # out-4k.mp4
```

## ৬) সমস্যা হলে

কোডটি এমন পরিবেশে লেখা যেখানে ইন্টারনেট/npm ছিল না, তাই **প্রথম রানে সামান্য ত্রুটি আসতে পারে** (এটা স্বাভাবিক, লগ দিলে ঠিক করা যায়):

| লক্ষণ | সম্ভাব্য কারণ ও করণীয় |
|---|---|
| `npm install` ব্যর্থ | `package.json`-এর কোনো ভার্সন মেলেনি — লগের বার্তাটি আমাকে দিন |
| `module not found` (`@remotion/google-fonts/HindSiliguri` বা `TiroBangla`) | ফন্ট-মডিউলের নাম আমার জানা থেকে লেখা — লগ দিন, ফন্ট বদলে দেব |
| টাইপ/রেন্ডার ত্রুটি (World/Characters/Scenes) | প্রথম রেন্ডারে ঘর-গাছ-চরিত্রের স্থান বা আকার সামান্য ঠিক করা লাগতে পারে — লগ বা একটা ফ্রেমের ছবি দিন |
| ক্যাপশনের লাইন-ভাঙা বা পটির মাপ একটু অন্যরকম | আসল Hind Siliguri ফন্টে প্রথমবার দেখা হচ্ছে — একটা ফ্রেমের ছবি দিন |
| `.mp3` import ত্রুটি | `declarations.d.ts` আপলোড হয়েছে কিনা দেখুন |
| `render.yml` কাজই করছে না | ফাইলটি হুবহু `.github/workflows/render.yml` পথে আছে কিনা দেখুন |
| 4K খুব ধীর | ক্যাপশনের ঝাপসা পটি বন্ধ করলে কিছুটা হালকা হয় (`Captions.tsx`-এ `backdropFilter` ও `WebkitBackdropFilter` লাইন দুটি মুছুন) |

## ৭) ঐচ্ছিক: Hyperframes ওভারলে

`hyperframes.html` মূল ভিডিওর জন্য **আবশ্যক নয়** — মূল ভিডিওতে ক্যাপশন Remotion থেকেই (`Captions.tsx`) আসে। এটি একই ক্যাপশনের আলাদা স্বচ্ছ HTML ওভারলে/ব্যাকআপ।

- **ব্রাউজারে দেখতে:** ফাইলটি `story01.mp3`-র সাথে একই ফোল্ডারে রেখে `hyperframes.html?preview=1` খুলুন (ক্লিকে প্লে/পজ, ←/→ = ১ সেকেন্ড)। `?t=১৫` দিলে ১৫ সেকেন্ডের ফ্রেম।
- **Actions-এ:** Run workflow-এ **hyperframes** টিক দিলে একটি আলাদা ঐচ্ছিক জব `npx hyperframes render` চালানোর চেষ্টা করে। Hyperframes-এর আসল কমান্ড আমি যাচাই করতে পারিনি, তাই এটি ব্যর্থ হতে পারে; ব্যর্থ হলে মূল HD/4K রেন্ডারে কোনো প্রভাব পড়ে না।
- `scenes.ts`-এর টাইমিং বদলালে এই ফাইলের ভেতরের ডেটা আবার তৈরি করতে হয় (আমাকে জানালে করে দেব)।
